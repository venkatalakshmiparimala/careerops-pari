LeaseI — Agentic AI Platform for Affordable Housing Document Analysis & Ticket Investigation
Built a LangGraph orchestration system (Triage → Configuration → Historical Incident → Structured Data → Reasoning → Validation → Escalation nodes) with shared TypedDict state across all nodes; FastAPI service for document uploads and ticket submissions; SQLite storage written to swap to PostgreSQL with minimal friction. Retrieval is TF-IDF cosine similarity -- a deliberate starting point, not the final design: hybrid dense+BM25 with reranking is documented as the next step. Confidence scores are hand-tuned constants (0.8 for a matched setting, 0.6 for a similar ticket) rather than computed from retrieval signals -- the clearest remaining gap. Live HUD User API integration (Bearer-token auth, correct endpoint shapes) for real-time income-limit lookups on eligibility tickets. Validation node strips evidence-free claims and flags them unsupported rather than presenting them at face value; escalation packet fires when top-ranked cause confidence falls below threshold. Read-only safety boundary hard-coded and test-verified: the system never auto-resolves eligibility, configuration, or calculation decisions for tenants regardless of confidence score -- the deterministic compliance engine and human staff remain the source of truth, enforced in code not just documented. Validated end-to-end: correctly diagnosed a misconfigured property setting as the root cause of an incorrect ineligibility result -- without needing the hybrid retrieval layer still on the roadmap.
