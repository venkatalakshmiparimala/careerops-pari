## Block F — STAR+R Stories

### Story 1 — LeaseI: Replacing Manual Compliance with AI (Flagship)
**Situation:** Lease compliance investigation is manual, slow, and error-prone — staff manually read lease documents, cross-reference policies, and handle every tenant escalation by hand.
**Task:** Build an AI system that automates the full compliance investigation workflow, with responsible AI controls ensuring humans stay in the loop for regulated decisions.
**Action:** Built LeaseI — 3-surface AI platform (Document Intelligence, Support Ticket Investigation, Tenant Self-Service) with 8 LangGraph agents. Hand-rolled TF-IDF RAG pipeline (OCR → chunking → hybrid search → reranking). Confidence-gated HITL escalation. Deterministic guard for every regulated call — LLM reasons; human or rule-engine decides.
**Result:** 93.6% precision, 87.9% F1 across 1,240 test cases. 100% citation correctness. 0% unsupported-claim rate. Safety boundary adversarially tested — never auto-resolves eligibility or financial decisions.
**Relevance:** This company's product replaces manual compliance work with software. LeaseI is a proof-of-concept for that exact value proposition.

### Story 2 — Intuit: AI Financial Features Owned End-to-End
**Situation:** Intuit needed LLM-powered financial summary and query-answering features, but with zero tolerance for hallucination or data leakage.
**Task:** Own the full lifecycle: discover use cases, build the AI features, production guardrails, evals, and iterate.
**Action:** Built Python/FastAPI services integrating Anthropic Claude with RAG grounding, structured-output schemas, input validation, sensitive-data redaction, and fallback paths. Built LLM-as-judge eval harness with golden datasets and CI regression detection. Shipped monitoring via OpenTelemetry.
**Result:** Caught 3 prompt regressions before release. Zero hallucination incidents post-deployment. Full citation traceability on all AI-generated financial summaries.
**Relevance:** Directly maps to "AI-powered features" + "end-to-end ownership" + "financial institutions."

### Story 3 — Entrata: HUD Income Limit ETL — Compliance Pipeline at Scale
**Situation:** Federal HUD income limits update annually. Every error directly affects resident housing eligibility — wrong income limits mean wrong eligibility decisions.
**Task:** Maintain and evolve the ETL pipeline that loads federal HUD data into 180K domain records with full validation and rollback.
**Action:** Owned this pipeline for 7 consecutive annual cycles. Built validation, rollback checks, and compliance enforcement. Monitored each release and resolved discrepancies before they reached production.
**Result:** Zero compliance violations across 7 annual release cycles. 180K records updated correctly each cycle.
**Relevance:** Shows compliance data ownership, relational database management, and end-to-end ownership of a critical production system.

### Story 4 — Entrata: Automation Eliminating 80% of Manual Work
**Situation:** Operations team manually processed recurring data tasks, consuming significant engineering and ops time weekly.
**Task:** Eliminate manual work through automation tooling.
**Action:** Built Python/Bash automation scripts and internal debugging/data investigation tools. Systematically replaced manual workflows with automated equivalents.
**Result:** 80% reduction in manual operational work. 40% reduction in triage time.
**Relevance:** Aligns with "AI-powered features that automate historically manual compliance work" — shows pattern of replacing manual work with software at scale.

### Story 5 — AgentProbe: Evaluation Infrastructure for AI Features in Production
**Situation:** When building AI features, there's no systematic way to detect quality regressions before release — hallucinations and retrieval failures only surface in production.
**Task:** Build evaluation infrastructure that catches quality drops in CI before they reach production.
**Action:** Built AgentProbe — 15-endpoint FastAPI backend with 5-metric LLM-as-judge eval engine (factual accuracy, hallucination rate, retrieval quality, completeness, compliance). 3 LangGraph agents for multi-step evaluation and auto-remediation. CI-integrated regression detection blocks deploys when quality drops.
**Result:** Used to evaluate LeaseI across 1,240 test cases. Now used at Intuit for production LLM features.
**Relevance:** Positions Parimala as someone who builds not just AI features but the infrastructure to make them reliable — strong signal for a team that cares about compliance accuracy.
